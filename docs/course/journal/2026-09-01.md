## Summary of Major Events from Today

**DRAFT — repo-sourced. Review every sentence.**

**The robot drove on command for the first time**: all four basic moves at 250 deg/s, with the
encoder deltas clean and symmetric — forward −366/+366, backward +367/−367, and turns at ±217 — and
the operator confirming **by eye** that each labelled move matched what the robot actually did. The
built robot turned out to differ from the plan in a way that matters: it carries **two colour
sensors, on ports C and D, not one**, along with the two drive motors on ports A and B and a single
unidirectional roller-ball caster at the back. The colour sensors were **re-mounted underneath the
robot** later the same day, dropping from roughly 51 mm — about three times too high — to near LEGO's
stated 16 mm optimum, which also made it possible to run colour and motors in the same session. Two
numbers were corrected against real hardware: the motors' ceiling is **930 deg/s**, not the 660 that
had been assumed, and `rgbi()` returns 0–1024. A latent software bug was caught by checking the code
against the day's real drive data: the odometry summed the raw, equal-and-opposite encoder counts, so
a forward move integrated to **zero distance**, and the drive helper applied no sign at all, so a
command to drive straight would have **spun the robot in place**; both were fixed. A first look at
colour was taken on **substitute** surfaces only — name cards, paper, khaki, with no yellow and no
tape — and it showed that glossy surfaces saturate the green and blue channels at 1024 and become
indistinguishable, so the real mission surfaces were still owed a measurement.
