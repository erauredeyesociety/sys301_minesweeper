## Summary of Major Events from Today

**DRAFT — repo-sourced. Review every sentence.**

The four real mission surfaces were measured for the first time, on the actual classroom carpet with
the actual sticky notes and the actual blue tape: **carpet reads reflectance 3–9, blue tape 7–9,
yellow notes 51–73, and pink notes 97 and above.** Running the team's already-written detection code
**unmodified** over those captures showed that it fails: yellow was **invisible** to it, clearing the
threshold on **0 %** of samples, while the blue boundary tape tripped it on **100 %** — so as shipped,
the robot would have armed cleanly, swept, missed every yellow mine, and counted the boundary as
mines. The reason was not the hue collision anyone predicted; the carpet's total signal is only about
**79 ADC counts**, so the statistical spread the rule divides by is smaller than a single count, which
also means that turning the sensitivity knob up would not have helped. The detector was replaced with
a plain brightness rule — **count anything reading 30 or brighter** — which has a **43-point gap with
zero overlap** between the floor and the mines, works whatever colour the mines turn out to be, and
leaves the blue tape sitting inside the carpet band where the mine rule cannot see it at all. That
rule was then **proven on the floor twice, untethered on battery**: the robot found a real pink note
at reflectance 99 and a real yellow note at 62 while driving, and named both colours correctly. Four
line-following runs were attempted and three failed, each for a different and diagnosable reason —
including one where the robot circled for a whole 40-second run because a steering sign was inverted,
turning the correction into positive feedback — and five separate bugs were found in the mission code
that was already written, one of which would have silently lost two mines at the end of every lane.
The day also produced the hard planning fact that **full coverage of a 10-foot arena is unreachable in
a demo slot**: driving one lap of the border alone costs about 92 % of a five-minute run.
