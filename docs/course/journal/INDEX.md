## ⚠ The repo copy is NOT the submission

The graded artifact is a **handwritten page, written in class, on the provided form.**
`[INFERRED]` — the instructions say only "the last 5-7 minutes each day independently writing"; the
handwriting and the printed form come from the example scan, not from a stated rule, and how the pages
reach Canvas (handed in, or scanned and uploaded) is **UNVERIFIED**.
`../source-material/Example Journal Entry.pdf` is a scan of a completed one: a printed sheet with ruled lines and
the fields **DATE**, **NAME**, **Question of the Day (QOD)**, **Answer for QOD**, and
**Summary of Major Events from Today**, filled in by hand in pen.

So:

| | |
|---|---|
| **The submission** | The handwritten sheet, written in the last 5–7 minutes of class, handed in / scanned for the 15 SEP Canvas due date (11:59 pm). |
| **The repo copy** | The **durable record** and the **drafting aid**. It exists so the content survives, so the Intro Report can be written from it, and so a missing day is visible at a glance. |

**Writing the markdown file does not earn a single point.** If the handwritten page does not exist, the
day is a −5 no matter how good the file is. Write the page first, transcribe second.

The point of transcribing at all: on 18 SEP the Intro Report needs a narrative of what happened on each
of six days, and paper in a backpack is not a searchable source. Transcribe the same day if possible —
handwriting you wrote in a five-minute rush is legible for about a week.

### The out-of-class rule applies here too

"You MAY NOT work on the project outside of class" (instructions p.1). Transcribing an entry you already
wrote by hand in class is recording, not working — but that is the operator's call to make, not this
repo's. See [../../scope.md § Critical Notes](../../scope.md#critical-notes).

## Conventions

- **One file per class day: `YYYY-MM-DD.md`.** No other naming. Six files, ever.
- Copy [TEMPLATE.md](./TEMPLATE.md) verbatim and fill it in. Do not restructure it — its fields mirror
  the printed form so transcription is mechanical in both directions.
- **Record the QOD exactly as it was posted on the board.** If you paraphrase it, the "entries clearly
  answer the question asked" criterion (20 pts) becomes impossible to verify later.
- **Sentence counts are per entry, not per project:** ≥4 answering the QOD, ≥4 summarizing the day,
  ≥8 total. Each short entry is its own −5.
- Specifics only. Names, part counts, Schrute Buck amounts, port letters, what broke. The rubric
  explicitly penalizes entries "so general as to be meaningless".
- Journal entries are a **personal reflection** — first person, your own performance and your own view
  of the day. This is not the team's shared status report.
