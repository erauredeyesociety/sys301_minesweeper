| [telemetry-over-bluetooth.md](./telemetry-over-bluetooth.md) | FORWARD-PLAN | **Untethered telemetry over BLE, and the analysis tools that consume it** — extends the row above with the Bluetooth-specific design. From LEGO's own published protocol reference: the hub streams IMU, both encoders, raw colour RGB and distance on request (`DeviceNotification`), and `print()` has a wire representation (`ConsoleNotification`) — but **there is no file-download message, so nothing can be pulled off the hub as a file**. Recommends the hybrid: live CSV + slow binary witness + a fixed on-hub ring buffer.
