# Course Compliance — READ FIRST

**Purpose.** This is a graded course project with rules that *override* engineering preference. A rule
violation costs real points or Schrute Bucks. Engineering elegance never justifies breaking one.

- **No work on the project outside of class.** Explicit course rule. It is in tension with using this
  repo out of class — that tension is the OPERATOR's to resolve, not ours to quietly resolve for them.
  Default posture out of class: **preparation and reference only** (research, reading, understanding
  the platform), not building the graded deliverable. If a requested task looks like it crosses the
  line, say so in one sentence and let the operator decide. Do not lecture; do not refuse ordinary work.
- **Role separation is enforced — 2 Schrute Bucks per violation.** Builder assembles and is the ONLY
  operator of the robot. Designer designs and may not touch supplies. Supplier alone handles money and
  supplies. Programmer writes code and may touch the robot ONLY to plug/unplug it from the laptop.
  When advising, address the right role — never tell the Programmer to go build something.
- **All written communication is a graded deliverable submitted in full.** Anything the team writes in
  Discord/email ends up in the submission. Keep it collectible from day one (`docs/course/team/communications.md`).
- **Face-to-face time costs money.** 1 Schrute Buck per person per minute beyond the daily 5-minute
  standup. Prefer a written answer over "let's meet about it" — that preference is literally budgeted.
- **The journal is the cheapest guaranteed score in the project** — 80 points, -5 per missing day.
  Never let a class day pass without an entry. ≥4 sentences on the Question of the Day, ≥4 on the day's
  events, 8 total, graded on grammar and specificity. Generic filler loses points; specifics do not.
- **The Intro Report must use the CSER 2022 / Elsevier Procedia MS Word template** (`../course/source-material/`).
  Word, single column, embedded figures, numbered sections. Draft content in `docs/course/report/`,
  but the submitted artifact is the Word file.
- **The dates are hard.** Demo 10 SEP · Peer review + journal 15 SEP · Report 18 SEP.
