# Runbooks — INDEX

Repeatable operator procedures. Written so a teammate can follow them under time pressure without
context. Every hub-touching step **an agent runs** goes through a script with an explicit timeout
([../directives/automation-first.md](../directives/automation-first.md)); steps a human performs at the
machine state the observation to expect instead.

The deploy route was chosen by demonstration, not by reading: REPL + base64 chunks → `/flash/lib` →
on-hub SHA-256 verify → import check, first run 2026-08-27. It is written up in
[deploy-to-hub.md](./deploy-to-hub.md); the background study that preceded it is
[../research/spike-prime-linux-toolchain.md](../research/spike-prime-linux-toolchain.md).
- [first-main-run.md](./first-main-run.md) — safe, bounded FIRST hardware run of src/main.py: deploy all src deps to /flash/lib, small arena + short timebox, walk each state glyph, abort = LEFT/RIGHT tap.
- [deploy-with-deps.md](./deploy-with-deps.md) — one command (`hub_programmer/deploy_deps.py ENTRY.py --apply`) that resolves a slot program's transitive local `src/` imports with `ast` and deploys each dependency to `/flash/lib` via the proven `upload.py`, then uploads+starts the entry via `slot_upload.py`. Resolver PROVEN on the host (main.py → 15 modules); the `--apply` orchestration is **[UNVERIFIED]** on hardware.
- [analysing-a-run.md](./analysing-a-run.md) — **after any untethered run, before you change the program that produced it.** Host-only, no hub. Download with `hub_programmer/download.py --all`, then `./scripts/analyse-run.py` (one run: verdict, motion, phase timeline, per-sensor threshold crossings **with the margin in both directions**, events, health, sparklines) and `./scripts/compare-runs.py` (many runs, one table). Explains every metric, what good and bad look like, and the trap that the newest FILE is usually not the newest RUN — 44 CSVs on disk were 15 distinct runs on 2026-09-08. **EXECUTED 2026-09-08**; every number in it was printed by the tools from real logs.
- [docs-rag-code-kb.md](./docs-rag-code-kb.md) — **our own source code is now a second knowledge base in the same docs-rag stack.** `./scripts/rag-code.py "question"` returns `file:line` + symbol citations from `src/`, `probes/`, `hub_programmer/`, `examples/` and `scripts/`; `docs` / `all` as a first word scope the same question at the prose corpus or both. Covers what was added (a `knowledge_bases` stanza + a compose override that mounts it, nothing vendored edited), why re-indexing is usually automatic, the one-command rollback, and the proof of every claim. **BUILT AND EXERCISED 2026-09-08** — 90 documents / 618 chunks, citations hand-checked against disk; the docs corpus was verified unchanged at 316 documents throughout.
